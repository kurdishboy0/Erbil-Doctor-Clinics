# 🏥 Erbil Doctor Finder

A patient guide website to help people find doctors and clinics in **Erbil, Kurdistan Region, Iraq**.

## Features

- 🔍 **Search** — Find doctors by name, specialty, clinic, or area
- 🏷️ **Filter** — Quick-filter by specialty and area
- 📍 **Google Maps** — Clickable location links for every clinic
- 📞 **Tap-to-Call** — Click phone numbers to call directly
- ⭐ **Patient Ratings** — Rate doctors 1-5 stars (saved in browser)
- 👨‍⚕️ **Doctor Profiles** — Detailed modal with bio, contact, and location
- 📱 **Mobile Friendly** — Fully responsive design

## Data

- **1,326** doctors
- **43** areas across Erbil
- **34** medical specialties

## Tech Stack

Pure HTML, CSS & JavaScript — no frameworks, no build step needed.

## Deployment

This site is deployed on [Netlify](https://www.netlify.com/) with continuous deployment from GitHub.
